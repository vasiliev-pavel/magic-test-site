# Тест по философии

Веб-тест в формате программы VTest: 30 вопросов, 30 минут. Вход по паролю.

## Как пользоваться

1. Ввести пароль, фамилию и имя, выбрать режим и нажать «Начать тест».
2. Режимы:
   - **С ответами** — ответ проверяется сразу: неверный подсвечивается красным,
     правильный — зелёным, изменить ответ после этого нельзя;
   - **Без ответов** — ответы можно менять до конца, правильность не показывается,
     только итоговый результат.

   По истечении времени тест завершается сам.
3. Результат (процент правильных ответов) показывается сразу и сохраняется
   в «Журнал результатов» этого браузера, оттуда его можно скачать в Excel.

## Где лежит тест

Тест хранится только в зашифрованном виде: `public/data/tests.enc`
(AES-256-GCM, ключ из пароля через PBKDF2). Без пароля вопросы и ответы
не прочитать — ни на сайте, ни в репозитории.

Исходник — `tests-src/Философия.dat` в формате VTest (Windows-1251). Эта папка
в `.gitignore` и в репозиторий не попадает. После правки теста зашифровать заново:

```bash
node tools/encrypt.mjs <пароль>
```

Формат `.dat`: заголовок `t` — время в минутах, `qt`/`qq`/`qqa` — разделы и число
вопросов, `rp` — баллы (0 — считать процент); вопрос начинается строкой `#`, затем
тип `A1`, текст и варианты, **первый вариант — правильный** (при показе варианты
перемешиваются). Несколько `.dat` в `tests-src` — на сайте появится выбор теста.

## Запуск локально

```bash
python -m http.server 8000 -d public
```
